# RishiDM Windows installer build

This branch builds RishiDM from AB Download Manager v1.11.1 under its Apache 2.0 license.

The RishiDM-specific Windows installer workflow is in `.github/workflows/rishidm-windows.yml`.

This work lives on the **rishidm-build** branch for isolated experimentation.
The draft pull request is solely for build testing and **must not be merged** into the NES/core source.

The first release is a development build, not the complete IDM feature set.
